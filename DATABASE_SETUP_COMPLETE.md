## 🚀 COMMANDES UTILES

### Démarrer le serveur de développement

```bash
cd /Users/macbook/Documents/NiangProgrammeur/site

# Démarrer le serveur Laravel
php artisan serve

# Démarrer Vite (dans un autre terminal)
npm run dev

# Vérifier les migrations
php artisan migrate:status

# Réinitialiser la BD
php artisan migrate:fresh --seed

# Tinker (console interactive)
php artisan tinker
```

### Vérifier la BD

```bash
# Accéder à MySQL
mysql -u root niangprogrammeur

# Lister les tables
show tables;

# Vérifier les utilisateurs
select id, email, name, role from users;

# Vérifier les formations
select id, title, slug, chapters_count, rating from formations;

# Vérifier les documents
select id, title, price, category_id from documents;

# Quitter
exit;
```

## 📖 STRUCTURE DES TABLES PRINCIPALES

### Users
```sql
id, name, email, password, role (admin/user/moderator/premium), 
email_verified_at, created_at, updated_at
```

### Formations
```sql
id, title, slug, description, content, cover_image, 
chapters_count, duration_hours, rating, reviews_count, 
views_count, enrollments_count, level, category, status
```

### Formation Chapters
```sql
id, formation_id, title, description, content, order, 
duration_minutes, views_count, status
```

### Quiz
```sql
id, formation_id, title, description, total_questions, 
passing_score, time_limit_minutes, shuffle_questions, 
show_correct_answers, attempts_count, average_score, status
```

### Quiz Questions
```sql
id, quiz_id, question, type (multiple_choice/true_false/short_answer), 
explanation, order, points
```

### Quiz Options
```sql
id, question_id, option_text, is_correct, order
```

### Documents
```sql
id, title, slug, description, category_id, price, 
cover_image, file_path, rating, views_count, downloads_count, 
status
```

### Documents Purchases
```sql
id, document_id, user_id, guest_email, purchase_price, 
payment_method, payment_status, created_at
```

### Forum Categories
```sql
id, name, slug, description, icon, color, order, is_active
```

### Badges
```sql
id, name, description, icon, color, criteria, order
```
